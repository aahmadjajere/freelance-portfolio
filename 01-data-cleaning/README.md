# Beginner Freelance Starter Portfolio

Five small, client-facing projects designed for a beginner software-engineering student seeking data-entry, web-research, spreadsheet, website, and Python gigs.

## Projects
1. Data Cleaning & Reporting — Excel-style data cleaning example with formulas and a summary dashboard.
2. Web Research Lead List — structured research template showing how to collect and validate public business information.
3. Responsive Landing Page — HTML/CSS landing page suitable for a small business.
4. Expense Tracker — vanilla JavaScript app with add/delete/filter and local storage.
5. Python CSV Analyzer — Python script that summarizes sales CSV data and exports a report.

## How to use this portfolio
- Put the folder on GitHub as a public portfolio repository.
- Add screenshots of projects 3 and 4 after opening them in a browser.
- Use the individual README files as the project descriptions on Upwork proposals.
- Do not claim paid client experience unless you actually obtain it.
